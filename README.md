# JENDL5-to-NeuCBOT

Конвертер данных (α,n) реакций из библиотеки **JENDL-5 Alpha-particle sublibrary** в формат программы **NeuCBOT**. Вычисляет нейтронный спектр — двойное дифференциальное сечение d²σ/dE_n — для каждой энергии налетающей α-частицы, с учётом угловых распределений из библиотеки ядерных данных.

---

## Поддерживаемые реакции

Все 13 реакций типа α + A → B + n, данные JENDL-5, α-энергия до 15 МэВ.

| Изотоп мишени | Реакция | Ядро-остаток | Каналы MT |
|---------------|---------|--------------|-----------|
| ⁶Li | ⁶Li(α,n)⁹B | B-9 | n₀–n₃ |
| ⁷Li | ⁷Li(α,n)¹⁰B | B-10 | n₀–n₄ |
| ⁹Be | ⁹Be(α,n)¹²C | C-12 | n₀–n₂ |
| ¹⁰B | ¹⁰B(α,n)¹³N | N-13 | n₀–n₄ |
| ¹¹B | ¹¹B(α,n)¹⁴N | N-14 | n₀–n₄ |
| ¹²C | ¹²C(α,n)¹⁵O | O-15 | n₀ только (Q = −8.50 МэВ) |
| ¹³C | ¹³C(α,n)¹⁶O | O-16 | n₀–n₄ (Q = +2.22 МэВ) |
| ¹⁴N | ¹⁴N(α,n)¹⁷F | F-17 | n₀–n₄ |
| ¹⁵N | ¹⁵N(α,n)¹⁸F | F-18 | n₀–n₄ |
| ¹⁷O | ¹⁷O(α,n)²⁰Ne | Ne-20 | n₀–n₃ (Q = +0.59 МэВ) |
| ¹⁸O | ¹⁸O(α,n)²¹Ne | Ne-21 | n₀–n₄ |
| ¹⁹F | ¹⁹F(α,n)²²Na | Na-22 | n₀–n₂₇ |
| ²³Na | ²³Na(α,n)²⁶Al | Al-26 | n₀–n₂₈ |

Нижний индекс nₖ означает: ядро-остаток остаётся в k-м возбуждённом состоянии. Q-значения указаны для основного состояния (n₀); для возбуждённых состояний Q уменьшается на энергию возбуждения.

## Физическая модель

### Кинематика (нерелятивистская двухтельная)

Реакция α + A → B + n рассматривается как двухтельный распад. Для каждой энергии налетающей α-частицы T_α и угла вылета нейтрона θ (в лабораторной СО):

$$T_n = \left(\frac{B + \sqrt{B^2 - AC}}{A}\right)^2$$

где

- $A = m_\alpha + m_A + T_\alpha$
- $B = \cos\theta \cdot \sqrt{m_\alpha T_\alpha m_n}$
- $C = \frac{m_B^2 - (m_A + m_\alpha - m_n)^2}{2} - T_\alpha(m_A - m_n)$

Все массы — атомные (AME2020), в единицах масс нейтрона × 939.565 МэВ.

### Q-значение и порог

$$Q = (m_\alpha + m_A - m_B - m_n) \cdot c^2$$

Порог реакции (при Q < 0):
$$E_{\text{порог}} = -Q\left(1 + \frac{m_\alpha}{m_A} - \frac{Q}{2 m_A}\right)$$

### Угловые распределения (разложение по полиномам Лежандра)

JENDL-5 хранит угловое распределение нейтронов в виде коэффициентов Лежандра (MF=6, LAW=2):

$$p(E_\alpha,\,\cos\theta) = \sum_{l=0}^{L} \frac{2l+1}{2}\,C_l(E_\alpha)\,P_l(\cos\theta)$$

Нормировка: $\int_{-1}^{1} p\,d(\cos\theta) = 1$.

Переход к энергетическому спектру: $p(E_n) = p(\cos\theta)\,\left|\dfrac{d\cos\theta}{dE_n}\right|$

## Установка и запуск

### 1. Получить данные JENDL-5

```bash
bash download_data.sh
```

Данные скачиваются с сервера JAEA. Файлы помещаются в `jendl5-a/` в формате ENDF-6.

### 2. Запустить конвертер для одного изотопа

```bash
python3 main.py -nucleus C_13
```

Обрабатывает все каналы реакции (MT=50, 51, ...) для ¹³C(α,n)¹⁶O.

### 3. Параметры командной строки

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `-nucleus NAME` | — | Изотоп мишени, обязательный. Примеры: `C_13`, `O_17`, `F_19` |
| `-points N` | 101 | Число точек по cos θ при вычислении угловых распределений |
| `-dE_a E` | 10000 (эВ) | Шаг сетки по энергии α-частицы (= 10 кэВ) |
| `-dE_n E` | 100000 (эВ) | Шаг сетки по энергии нейтрона (= 100 кэВ) |

Пример с нестандартными параметрами:
```bash
python3 main.py -nucleus O_17 -points 201 -dE_a 5000 -dE_n 50000
```

### 4. Обработать все изотопы

```bash
bash script.sh
```

### 5. Создать суммарный канал MT=4 (полная реакция)

```bash
python3 make_MT4_dir.py
```

Суммирует спектры по всем MT≥50 и записывает в директорию MT4.

### 6. Очистить выходные данные NeuCBOT

```bash
bash NeuCBOT_clear_JENDL.sh
```

## Промежуточные данные

Конвертер создаёт каталог `stage_1_data/` с рабочими файлами (их можно удалить после завершения). Окончательные данные для NeuCBOT записываются в `stage_2_data/`.

```
stage_1_data/
├── converted/El_A              ← ENDF-6 в читаемом формате
├── reshaped/El_A/
│   ├── MF3_MT<N>/              ← сечения σ(E_α) в барнах
│   └── MF6_MT<N>/NK1_NE<i>    ← коэффициенты Лежандра
├── angle_distribution/         ← p(cos θ, E_α) — угловые распределения
└── En_distribution/            ← p(E_n, E_α) — энергетические спектры (эВ)
```

---

## Выходные данные (формат NeuCBOT)

```
stage_2_data/<El>/<ElA>/JendlOut/
├── MT50/                       ← канал n₀ (основное состояние)
│   ├── cross-section           ← σ(E_α): E_α [МэВ], σ [мбарн]
│   ├── outputE0.0000           ← пусто (ниже порога реакции)
│   ├── outputE5.0000           ← спектр при E_α = 5.00 МэВ
│   └── outputE15.0000          ← спектр при E_α = 15.00 МэВ
├── MT51/                       ← канал n₁ (1-е возбуждённое)
│   └── ...
└── MT4/                        ← суммарная реакция (из make_MT4_dir.py)
```

### Файл `cross-section`

```
# E_a, MeV    XS, mb
0.00          0.0
0.01          0.0
...
15.00         <значение>
```

Шаг по E_α = dE_a (по умолчанию 0.01 МэВ = 10 кэВ). Ниже порога реакции — нули.

### Файл `outputE<X.XXXX>`

```
# Incident particle energy (MeV) =
# 5.00
#
# En.lab,MeV distribution
   0.100000  1.234e-02
   0.200000  2.567e-03
   ...
```

- Имя файла: `outputE` + E_α в МэВ (формат `%6.4f`)
- Первый столбец: E_n [МэВ], шаг dE_n (по умолчанию 0.1 МэВ)
- Второй столбец: p(E_n) × σ(E_α) [мбарн/МэВ]
- Физический смысл: интегрирование второго столбца по E_n даёт сечение σ(E_α) для данного MT
- Файл содержит `EMPTY`, если E_α вне диапазона данных JENDL или σ = 0

## Ограничения

- Только реакции (α,n). Другие каналы ((α,p), (α,γ), неупругое рассеяние) не реализованы.
- Максимальная энергия α-частицы: 15 МэВ (ограничение JENDL-5).
- Минимальный бин нейтронной энергии: 100 кэВ (первая точка E_n = dE_n).
- `make_MT4_dir.py` жёстко привязан к C_13 — перед использованием для других изотопов нужна доработка.
- Угловые распределения из JENDL-5 описаны в лабораторной системе отсчёта (LAW=2, LCT=2) — центр-масс-система не используется.
- Кинематика нерелятивистская: применима при T_α ≪ m_α c² ≈ 3727 МэВ, т.е. при T_α ≤ 15 МэВ точность достаточная.

## Структура данных JENDL-5

Источник: Japanese Evaluated Nuclear Data Library ver. 5, Alpha-particle sublibrary.  
Сайт: https://wwwndc.jaea.go.jp/jendl/j5/j5.html

Формат файлов: ENDF-6 (FORTRAN фиксированная ширина поля).  
Файлы: `jendl5-a/a_ZZZ-El-AAA.dat` (ZZZ — атомный номер, AAA — массовое число).

Ключевые секции ENDF-6:
- **MF=3**: сечения σ(E_α) по каналам MT
- **MF=6, LAW=2**: угловые распределения в виде полиномов Лежандра

---

## Источник масс ядер

Атомные массы: **AME2020** (Atomic Mass Evaluation 2020).  
Энергии возбуждённых уровней: **NuDat 3** (Национальная лаборатория Брукхейвен).

Данные хранятся в `chemistry.py` (словари `masses` и `masses_from_AME2020`) и в CSV-файлах в директории `level_schemes/`.
